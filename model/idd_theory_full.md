Аннотация
Представлена модель имманентной дискретной динамики, построенная на единственном первичном различении (cross) без внешних аргументов. В классическом пределе модель демонстрирует фазовый переход при критической плотности маркированных узлов fcrit​=1/2, численно подтверждённый на регулярных графах (pfinal​=0.490±0.049, n=100). Предложен эффективный групповой полевой формализм (GFT), постулирующий критические показатели ν=1, β=1/2, γ=1, η=0 и корреляционную длину ξ∼∣f−fc​∣−1. Разработано квантовое расширение на основе уравнения Линдблада, реализующее декогеренцию без коллапса волновой функции. Предварительные результаты указывают на связь времени декогеренции T2​ с критической плотностью. Количественная проверка предсказаний GFT и масштабирование на большие сети (n≥12) остаются открытыми вопросами.

1. Методологическая основа
1.1 Исходная проблема
Построение динамической модели, в которой время, пространство и причинность возникают эмерджентно из первичных различений, без априорно заданных внешних параметров.
1.2 Принятые принципы
Принцип	Описание
Имманентность	Все объекты определяются только через отношения внутри системы
Реляционность	Нет абсолютных свойств, только отношения между различéниями
Языковая гигиена	Запрещены ссылки на внешние сущности, не определённые в системе
Локальность	Обновления происходят только на основе локальной информации
Индуктивность	Структура порождается последовательностью различений
1.3 Ключевые решения
    1. Первичный акт — различение (cross) без аргумента, задающее начальное состояние
    2. Сеть строится индуктивно: каждое новое различение добавляет узел, связанный с существующим
    3. Динамика определяется правилом обновления на основе состояния детей узла
    4. Время возникает как последовательность асинхронных обновлений (с оговоркой о стохастической аппроксимации)

2. Формальное ядро
2.1 Первичное основание: различение
Акт различения cross не имеет аргумента и порождает первое состояние. Каждое последующее различение создаёт новый узел, связанный с существующим.
2.2 Построение сети
Сеть G=(V,E) строится индуктивно:
    • Узел v0​ — первое различение
    • Для каждого нового различении v выбирается родитель u∈V
    • Добавляется ориентированное ребро u→v
Класс InductiveNetwork реализует это построение.
2.3 Динамика: правило обновления
Состояние узла: s(v)∈{0,1}, где 1 соответствует отмеченному (маркированному) узлу.
Правило обновления (выведено из принципа локальности):
st+1​(v)=st​(v)⊕¬​u∈children(v)⋀​st​(u)​(2.1)
В терминах булевых переменных xv​=(1−sv​)/2∈{0,1} (1 — маркированный):
xt+1​(v)=1−xt​(v)−u∈children(v)∏​(1−xt​(u))+xt​(v)u∈children(v)∏​(1−xt​(u))(2.2)
Для листьев (узлов без детей): конъюнкция по пустому множеству считается истинной (⋀∅=True), поэтому правило обновления даёт:
st+1​(v)=st​(v)⊕¬(True)=st​(v)⊕0=st​(v)(2.3)
Таким образом, листья стабильны — их состояние не меняется.
2.4 Локальное время и причинность
Обновления происходят асинхронно: в каждый момент времени выбирается один узел и обновляется по правилу (2.1). Следует отметить, что используемая стохастическая реализация является аппроксимацией; полная конструкция локального времени требует частичного порядка событий, выводимого из отношений причинности в сети.

3. Геометрическая фаза и комбинаторная кривизна
3.1 Определение геометрической фазы
Геометрическая фаза возникает из структуры циклов в сети. Каждый цикл вносит вклад в кривизну узлов.
3.2 Комбинаторная кривизна Олливье
Для узла v с степенью deg(v) и циклами длин mi​, проходящими через v:
κ(v)=1−2deg(v)​−i∑​2−mi​(3.1)
Вес 2−m отражает экспоненциальное убывание вклада длинных циклов.
3.3 Функционал нестабильности
Мера "готовности" узла к изменению:
ε(v)=1−u∈children(v)⋀​s(u)(3.2)Φtotal​=v∑​ε(v)2(3.3)
3.4 Плотность активных циклов
Для каждого размера цикла k:
ck​=∣V∣#{активных циклов длины k}​(3.4)
Активным считается цикл, в котором все узлы маркированы.

4. Аналитические предсказания
4.1 Среднеполевое уравнение
Плотность маркированных узлов p=∣V∣1​∑v​xv​ эволюционирует как:
p˙​=(1−2p)(1−p⟨d⟩)(4.1)
где ⟨d⟩ — средняя степень.
4.2 Неподвижные точки и fcrit​=1/2
Уравнение (4.1) имеет неподвижные точки при p˙​=0:
1−2p=0⇒p=21​
Второй множитель 1−p⟨d⟩=0 даёт p=1/⟨d⟩, однако это значение не является неподвижной точкой полного уравнения, поскольку при p=1/⟨d⟩ множитель (1−2p)=0. Для связных сетей с ⟨d⟩>2 единственная устойчивая неподвижная точка:
fcrit​=21​(4.2)
4.3 Кинетическое уравнение для циклов
Эволюция плотности циклов:
dtdck​​=αk​pkck−1​−βk​k(1−p)ck​(4.3)
где αk​,βk​ — кинетические коэффициенты, определяемые топологией.
4.4 Корреляционная длина
Вблизи критической точки предсказывается:
ξ∼∣f−fc​∣−1,fc​=21​(4.4)

5.4 Время декогеренции T2​
Для суперпозиции двух классических состояний ∣a⟩ и ∣b⟩ время декогеренции определяется как:
T2​=min{t:∣⟨a∣ρ(t)∣b⟩∣<∣⟨a∣ρ(0)∣b⟩∣/e}(5.1)
На сети из 2 узлов получены следующие результаты:
    • T2​∝1/γdeph​ (подтверждено, коэффициент корреляции r>0.95)
    • T2​ максимальна при f≈0.5 (отношение T2​(0.5)/T2​(0.25)≈1.7)
Количественная проверка скейлинга T2​∼∣f−fc​∣−1 на больших сетях (n≥8) не дала однозначного подтверждения; для окончательных выводов требуется масштабирование на n≥12.

6. GFT-формализм как эффективный язык
В данном разделе представлен эффективный GFT-формализм — язык описания, позволяющий компактно записывать статические критические свойства модели. Формализм постулируется на основе соответствия с классической динамикой, а не выводится из первых принципов. Статистическая сумма Z(β) и критические показатели являются предсказаниями этого эффективного описания, требующими дальнейшей верификации.
6.1 Операторное представление
Гильбертово пространство H=⨂v∈V​C2. Оператор различения:
s^v​=σz(v)​(6.1)
Оператор обновления:
U^v​=X^v​⊗Π^v​+I^⊗(I^−Π^v​)(6.2)
где Π^v​=⨂u∈children(v)​∣0⟩⟨0∣u​.
6.2 Статистическая сумма
Z(β)=(4πβ1​)∣V∣∫v∏​dϕv​e−4β1​∑v​ϕv2​v∏​e−iϕv​(1+eiϕv​)deg(v)(6.3)
6.3 Континуальный предел
В пределе ∣V∣→∞, β→βc​ возникает континуальное действие:
S[ϕ]=∫dDx(21​(∇ϕ)2+2m2​ϕ2+4!λ​ϕ4)(6.4)

7. Квантовое расширение: декогеренция без коллапса
7.1 Принципы квантования
Квантовое расширение строится на следующих принципах:
    1. Каждому узлу сети сопоставляется кубит Hv​=C2, что соответствует двум возможным классическим состояниям (маркирован/немаркирован).
    2. Оператор различения s^v​=σz(v)​ наследует классическую наблюдаемую.
    3. Классическое правило обновления заменяется унитарным оператором U^v​, действующим на кубит v и контролируемым состоянием детей. Это минимальное квантовое расширение, сохраняющее классическую динамику на диагонали.
7.2 Гильбертово пространство и операторы
Полное пространство H=⨂v​Hv​.
Оператор различения: s^v​=σz(v)​
Оператор обновления: U^v​=X^v​⊗Π^v​+I^⊗(I^−Π^v​), где Π^v​=⨂u∈children(v)​∣0⟩⟨0∣u​.
7.3 Уравнение Линдблада без коллапса
dtdρ​=v∑​γ(U^v​ρU^v†​−ρ)+v∑​γdeph​(σz(v)​ρσz(v)​−ρ)(7.1)
Ключевое свойство: нет проективных членов P^v​ρP^v​, только унитарные преобразования и дефазировка.
7.4 Результаты
Для сети из 2 узлов:
    • Начальная чистота: 1.0 → финальная: 0.25 (максимально смешанное состояние)
    • Энтропия: 0 → 1.386 (ln 4)
    • T2​∝1/γdeph​ (подтверждено)
    • T2​ максимальна вблизи fcrit​=0.5

8. Корреляционная функция
8.1 Определение
Для квантового состояния корреляционная функция определяется как:
G(r)=⟨si​sj​⟩−⟨si​⟩⟨sj​⟩(8.1)
где r=dist(i,j), s=σz​.
8.2 Методика вычисления ξ
Корреляционная длина ξ извлекается из фитирования:
G(r)=Ae−r/ξ(8.2)
методом наименьших квадратов. Для сетей размера n=8 доступны расстояния r=1,2,3,4 (для цикла) и r=1,2 (для 3-регулярного графа).
