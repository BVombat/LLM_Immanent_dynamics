# Метод реинкарнационного переноса конспекта

Рабочий метод длительной работы с LLM без переполнения контекста (~1M токенов).  
Родился из практической задачи — построения физической модели Имманентной дискретной динамики (ИДД).  
Модель не подтвердилась в рамках N=20, но метод остался жив.

---

---

## Три роли

| Роль | Количество реинкарнаций | Когда появилась |
|------|------------------------|----------------|
| Генератор | 10 | С первой сессии |
| Рецензент | 3 | Сразу (для проверки релевантности) |
| Суперрецензент | 3 | Позже (для сборки этапов) |

---

## 5 наблюдаемых паттернов (маячки)

1. **Инициатива** — модель предлагает следующие шаги исследования
2. **Удержание цели** — не сбивается с главной линии через реинкарнации
3. **Системная критика** — находит противоречия в своих же выводах
4. **Оценка целого** — собирает разрозненные этапы в картину
5. **Сохранение идентичности** — после переноса конспекта «вспоминает» роль и стиль

---

## Ограничения метода

- Ручная работа — перенос конспекта между сессиями делает человек
- Дисциплина — без жёсткого следования ролям метод разваливается
- Не для коротких задач — овчинка выделки не стоит
- Риск убеждения — LLM может убедить в своей правоте, даже если вы сомневались
